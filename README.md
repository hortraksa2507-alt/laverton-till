# Laverton Award Bakery — Price Board

Customer-facing price board for Laverton Award Bakery. Shows menu items with photos, prices, and category filters. Edit mode lets staff update prices and upload photos; changes persist via `localStorage`.

## Run locally

```bash
npm install
npm run dev
```

Open the URL shown in the terminal (usually http://localhost:5173).

## Production build

```bash
npm run build
```

Static output is written to `dist/`. Preview it with `npm run preview`.
